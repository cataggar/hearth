### S1 decision and remaining work

Reject the **proposed direct guest-ring** candidate under the written contract.
The exact kernel processes unnegotiated INDIRECT, while original Flint walks
only NEXT and caps collected chains at 16. The existing kernel API has no
negotiated-feature enforcement switch for that descriptor branch. A userspace
scan of live guest descriptors cannot securely enforce the rule: guest memory
can change after the scan and before the kernel reads it. Neither advertising
INDIRECT nor silently accepting its new semantics is permitted by this proposal.
A shadow/mediated-ring design or an explicit amended semantic contract would
be a different, separately justified experiment. This is not a claim that all
possible vhost designs are unsafe or that the kernel failed the observed
detach/CoW/bounds tests.

Errorfd-driven fatal queue handling plus a carefully proven consumed/used
invariant may permit authoritative progress in a restricted design; the
controlled reseeding case illustrates that avenue rather than declaring it
impossible. It does **not** establish pause ACK/IRQ coherence, lost-wakeup safety,
format-v2 traffic restore, arbitrary guest mutation or reset-generation races.
Those full VM tests and the net-only functioning A′ adapter remain **unrun**.
No backend selector, vhost device jail entry or dispatcher was added; no broad
confinement change or sibling runtime optimization was imported. The exact
separate shared jail prerequisite was requested but not received/applied at
this report boundary.

Default adoption remains rejected without a current TAP consumer. Qualified
performance execution also remains blocked by independently verified host
saturation; noise N, paired confidence intervals and vhost CPU/goodput deltas
are **undefined**, not zero. Original known readiness failures are preserved,
but are not the safety-decision rationale. The execution plan remains active/
